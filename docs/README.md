# daedalus-mono

Polyglot monorepo for icarus612's personal projects: Flask/Next.js/React/Svelte apps, Go/Python/Bash libraries, and a git-submoduled npm package, orchestrated with pnpm + Turborepo (plus a legacy, unused Bazel `WORKSPACE`).

This `/docs` tree is the single source of truth for documentation in this repo. In-project `README.md` paths and their `/docs` counterparts are symlinked to each other so the same content never exists twice — edit the real file, never the symlink. The symlink points **into** `/docs` for most packages; for the handful of directories that CI copies verbatim into satellite repos (all `libs/golang/*`, the five `maze-runner` implementations, and the `dots-js` submodule), the real file stays in the source tree and the `/docs` path is the symlink — see [known-issues.md](known-issues.md#symlink-direction-exception-for-ci-synced-packages).

> **Root `README.md` is generated.** The repo-root `README.md` (one level up from this file) is regenerated by `.github/workflows/update-readme.yml`, which runs `libs/bash/github-actions/create-mono-file-tree.sh` and commits the result. It is a directory-tree listing, not hand-maintained documentation — don't edit it directly, and don't expect it to match this `/docs` tree's level of detail.

## Tech stack at a glance

Versions below are verified from the manifest/lockfile named; see [conventions.md](conventions.md) and each package's own doc page for specifics.

- **Monorepo orchestration**: pnpm (declares `9.1.0` in root `package.json#packageManager`; the pnpm binary actually resolving in the explored environment was `8.15.1` — unverified whether that drift is intentional, see [known-issues.md](known-issues.md)) + Turborepo `2.5.5` (`turbo.json`).
- **Bazel**: root `WORKSPACE` references `rules_nodejs 4.4.6`, `rules_python 0.4.0`, `rules_go v0.29.0` — legacy, effectively unused (only one stray empty `BUILD` file remains outside it).
- **Go**: per-module versions `1.21`–`1.24.2`, no `go.work` file; each module is fully independent.
- **Python**: Poetry (`^3.11`, one `^3.8`) for the "proper" libs; Flask apps pin old `requirements.txt` versions (Flask `2.3.3`, Werkzeug `2.3.7`); `market-bots` uses unpinned `requirements.txt`.
- **Next.js**: `^12.1.5` / React `^18.0.0`, legacy Pages Router + `next export`, not the App Router.
- **CRA (create-react-app)**: two libraries still on `react-scripts 2.1.1` with React `16.6–16.8` — frozen/old.
- **Svelte**: one package on Svelte `^5.0.0` (runes) + Vite `^5.4.0` + Storybook `^8.6.14` — the only modern frontend stack in the repo.
- **dots-js**: a git submodule pointing at an independently published npm package, not workspace-managed.

## Critical thing to know before touching tooling

`pnpm-workspace.yaml` only globs 2 levels deep under `libs/*/*`. A large chunk of the repo — all of `libs/javascript/node/*`, `libs/javascript/react/*`, `libs/javascript/svelte/*`, all of `libs/python/neural-networks/*`, and `libs/python/tensorflow/open-ai-gym` — is **silently invisible** to `pnpm install` and every `turbo build/dev/lint/test` run, even though those packages declare `workspace:*` devDependencies. See [known-issues.md](known-issues.md#workspace-glob-excludes-a-third-of-the-repo) for the full list and verification method.
