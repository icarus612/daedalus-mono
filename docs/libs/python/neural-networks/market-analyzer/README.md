# Market Analyzer (Neural Networks)

An LSTM-based stock-market model experiment, in two forms. `classes/analyzer.py`'s `Analyzer` class wraps a Keras `Sequential` LSTM model (load-or-build-then-train pattern, model persisted to `models/market_analyzer.keras`) — but `__init__` calls `self.build()` while the only build method defined is `build_new()`, so instantiating this class as written would raise an `AttributeError`; not executed to confirm. Its `train()` method also divides input data by `255.0` (an image-normalization step) despite this being LSTM stock data, suggesting it was adapted from the digit-recognition code without full review. `classes/gpt.py` is a separate, simpler, non-class procedural script (LSTM built directly with `Sequential`, reads a hardcoded `stock_data.csv`) — the filename suggests it was generated by an LLM as a reference/starting point rather than hand-written.

**Path:** `libs/python/neural-networks/market-analyzer`
**Workspace name:** `lib.python.neural-networks.market-analyzer`

## Stack
- Python `^3.11` via Poetry (`pyproject.toml`, no `poetry.lock` present). `requirements.txt` (pinned versions) lists real dependencies — `numpy`, `pandas`, `requests`, `pytest`, `pre-commit`, `robin-stocks`, `vaderSentiment`, `pyotp`, etc. — but notably no `tensorflow` or `scikit-learn` pin, despite both being imported in `classes/analyzer.py`.

## Structure / entry points
- `classes/analyzer.py` — `Analyzer` class: `build_new()` (LSTM `Sequential` model), `train()`, `test()` (stub, `pass`), `save()`, `get_summary()`.
- `classes/gpt.py` — standalone procedural script building/training an LSTM on a hardcoded `stock_data.csv`; not wired to the `Analyzer` class.

## Usage
- `package.json` scripts (`install`, `build`, `lint`, `dev`) shell out to `libs/bash/build-tools`'s `py-install`/`py-build`/`py-lint`/`py-dev` wrappers, declared via a `workspace:*` devDependency on `lib.bash.build-tools`.
- No `bin` entries; run scripts directly.
