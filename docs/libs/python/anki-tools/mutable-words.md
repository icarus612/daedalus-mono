# Mutable Words deck

`Languages::Russian::3. Mutable Words` — a four-subdeck Anki deck built from
`~/Downloads/russian_vocabulary.xlsx`, generated by `anki-vocabulary-source` + `anki-mutable-words` +
`anki-mutable-words-audio`, and installed at
`Languages::Russian` slot `3.` by `anki-renumber-russian-decks`. Execution record:
[`mutable-words-runbook.md`](mutable-words-runbook.md).

## Design

Four purpose-built note types, one per workbook sheet, each with its own subdeck:

| Subdeck | Note type | Notes | Templates/note | Cards |
|---|---|---|---|---|
| `a. Nouns` | `Russian - Mutable Nouns (Ellis Version)` | 541 | 2 | 1082 |
| `b. Verbs` | `Russian - Mutable Verbs (Ellis Version)` | 179 | **4** | **716** |
| `c. Adjectives` | `Russian - Mutable Adjectives (Ellis Version)` | 152 | 2 | 304 |
| `d. Adverbs` | `Russian - Mutable Adverbs (Ellis Version)` | 132 | 2 | 264 |
| **Total** | | **1004** | | **2366** |

**Verbs get four cards, not two.** Each verb note carries both aspects (imperfective and perfective),
and each gets a full recall pair — `Card 1` imperfective → translation, `Card 2` translation →
imperfective, `Card 3` perfective → translation, `Card 4` translation → perfective — rather than
merging both aspects onto one two-card note. Each template side carries exactly one audio field, for
the aspect that side is about.

**Adverbs split two slash-joined rows into four.** The workbook's `направо / справа` and `налево /
слева` rows each name two distinct adverbs, not one with a shorthand slash. `mutable_words_plan.py`'s
`ROW_SPLITS` table splits each into two independent notes (each getting its own GUID, its own audio),
sharing everything except `Adverb`/`Translation`/`Stress`. 130 real rows split into 132 notes.

**Field sets are the workbook's own column headers, verbatim, with three departures**:

| Departure | Reason |
|---|---|
| `#` → `Rank` | Anki field names may not start with `#`. |
| `English` → `Translation` | Matches the existing `… (Ellis Version)` note-type family's naming, and the reverse card is built around it. |
| `Status` dropped | It reads `"New"` on 1002 of 1002 real rows (100%, no other value anywhere) — a fully uniform column carries no information, and Anki's own scheduler supersedes it. |

Per-sheet field counts: Nouns 13, Verbs 15, Adjectives 14, **Adverbs 10**. `AudioRefs` is last in
every set and is never referenced by any template — rendering it would autoplay every clip back to
back, which is exactly the bug the plain-text `Audio` field plus the random-picker JS (below) exists
to avoid.

**Dash-only cells are preserved verbatim, never normalized.** 143 of them carry real linguistic
meaning: `Nouns.Plural` (107 cells, "no plural in everyday use") and `Adverbs.Comparative` (36 cells,
"no comparative form"). The existing immutable-words precedent collapses `—`/`–`/`-`/`--` to `""`;
this deck deliberately does not copy that rule.

**The workbook is never a build input.** `anki-vocabulary-source` converts it once into four
committed TSVs under `anki_tools/data/russian-vocabulary/` (with a provenance `README.md` alongside
them) — the workbook lives outside the repo and outside version control, so a build reading it
directly would not be reproducible, diffable, or reviewable. Nothing downstream of that conversion
ever imports `openpyxl` (resolved version: `3.1.5`, added to `[project] dependencies` since
`vocabulary_source.py` imports it at module level, not as a dev-only dependency).

**Two voices, selected at the call site.** `mutable_words_plan.VOICE_SLOTS = ("f1", "m2")` — Alisa and
Nester Surovy — is the single place this deck's two-voice decision is written down.
`elevenlabs_tts.VOICES` / `DEFAULT_VOICES` / `--all-voices` are untouched; every other caller of that
module is unaffected. Cost: 1183 base-word audio items (1004 words + 179 verbs' second aspect) × 2
voices = 2366 `(word, slot)` pairs; 14 of those already existed on disk (the 7 words this deck shares
with the immutable-words deck: `кафе`, `кино`, `кофе`, `метро`, `пальто`, `просто`, `согласно`), so
the real spend was 2352 network requests — computed against the Anki media directory (the
authoritative location), never the review output directory, so a shared file is never re-purchased.

## Shared modules hoisted out of the immutable-words lane

Building this deck required lifting two pieces of code the existing immutable-words deck already
depended on, so both decks now share one implementation instead of two copies drifting apart:

- **`anki_tools/anki_identity.py`** — `base91`, `guid_for_row(russian, pos)`, `notetype_id_for_name`.
  Pure hashing (`hashlib` only, no `anki`, no `requests`) — deterministic note GUIDs and note-type
  ids, never minted by Anki and never from Python's salted `hash()`. Moved out of
  `immutable_words.py` / `immutable_words_plan.py` verbatim; every existing GUID is unchanged.
- **`anki_tools/card_audio.py`** — `audio_block(field, dom_id, state_key)`, the random-audio-picker
  `<div>`+`<script>` block, parameterized so each note type's audio field, DOM id, and per-render
  state key are independent. `immutable_words_plan.rewrite_audio_playback`'s output is
  byte-identical before and after the hoist.

## Tooling

| Command | Module | Purpose |
|---|---|---|
| `anki-vocabulary-source` | `vocabulary_source.py` | Convert the workbook into the four committed TSVs. |
| `anki-mutable-words` | `mutable_words.py` | Build/export the deck package (`.apkg`), or `--dry-run` to print counts only. |
| `anki-mutable-words-audio` | `mutable_words_audio.py` | Generate any missing recordings, resumable by design. |
| `anki-renumber-russian-decks` | `renumber_russian_decks.py` | Free up the `3.` slot by renumbering three sibling decks. |
| `anki-immutable-words` | `immutable_words.py` | Build/export the `2. Immutable Words` deck package. |
| `anki-elevenlabs-tts` | `elevenlabs_tts.py` | Standalone ElevenLabs TTS for one word or a word list. |

The last two commands existed before this run but were never documented — see
[README.md](README.md#anki-immutable-words) for their own sections.

### `anki-vocabulary-source`

```
anki-vocabulary-source [--workbook PATH] [--out-dir DIR] [--dry-run]
```

| Flag | Default | Meaning |
|---|---|---|
| `--workbook` | `~/Downloads/russian_vocabulary.xlsx` | Source `.xlsx`. |
| `--out-dir` | the packaged `anki_tools/data/russian-vocabulary/` | Where to write `nouns.tsv` / `verbs.tsv` / `adjectives.tsv` / `adverbs.tsv`. |
| `--dry-run` | off | Print per-sheet row counts and write nothing. |

Header validation is strict: a sheet whose header row doesn't exactly match the expected columns
(order included) raises rather than silently mis-mapping a field. Any cell containing a tab, CR, or
LF is rejected by name (sheet/row/column) — that is what makes TSV a lossless container here.

### `anki-mutable-words`

```
anki-mutable-words [--source-dir DIR] --out PATH [--audio-dir DIR] [--collection PATH]
                    [--no-media-dir-fallback] [--dry-run] [--force]
```

| Flag | Default | Meaning |
|---|---|---|
| `--source-dir` | the packaged TSVs | Directory holding the four TSVs. |
| `--out` | — | Where to write the `.apkg`. Required unless `--dry-run`. |
| `--audio-dir` | none | Already-generated audio to attach as real media before export. Omitted: exports with `AudioRefs` `[sound:…]` tags naming the files as used but no bytes attached. |
| `--collection` | auto-detected | Override the collection path used only to read the source note-type CSS/scalars — never written. |
| `--no-media-dir-fallback` | off | Disable the automatic fallback to the real Anki media directory for a file `--audio-dir` doesn't have (see [Discrepancies](#discrepancies-found-during-the-run)). |
| `--dry-run` | off | Print the per-deck table; open no collection, write nothing. |
| `--force` | off | Allow `--out` to overwrite an existing file. |

Never mutates the real collection — it opens the source collection read-only-in-effect (for the CSS
and a handful of scalars) and asserts its mtime is unchanged afterward.

### `anki-mutable-words-audio`

```
anki-mutable-words-audio [--source-dir DIR] [--sheet {Nouns,Verbs,Adjectives,Adverbs}]
                          [--output-dir DIR] [--anki-media-dir DIR] [--limit N]
                          [--dry-run] [--yes]
```

| Flag | Default | Meaning |
|---|---|---|
| `--source-dir` | the packaged TSVs | Directory holding the four TSVs. |
| `--sheet` | all four | Limit to one sheet; repeatable. |
| `--output-dir` | `elevenlabs_tts.DEFAULT_OUTPUT_DIR` | Where to write `.mp3` files. |
| `--anki-media-dir` | auto-detected | Override the Anki media directory. |
| `--limit N` | none | Process only the first N pending words. |
| `--dry-run` | off | Print the cost table and voice roster; issue nothing. |
| `--yes` / `-y` | off | Skip the confirmation prompt (required above 1 request). |

**Resumability is the default, not a flag.** Every run recomputes the pending set against the Anki
media directory, so an interrupted run resumed later re-requests only what's still missing — no
checkpoint file, the media directory *is* the state. The `RequestBudget` is sized to the pending
count, never to the total, so a runaway word list is stopped by the same choke point every other
caller of `elevenlabs_tts` goes through.

### `anki-renumber-russian-decks`

```
anki-renumber-russian-decks [--collection PATH] [--backup-dir DIR] [--no-backup]
                             [--dry-run] [--yes] [--revert]
```

Renames the three `Languages::Russian` sibling decks (`3. Sentences (lingo llama)` → `4.`, `4. 100
Words & Phrases` → `5.`, `5. Master Russian 300+` → `6.`) to free the `3.` slot for this deck, in
**reverse order** (`5.`→`6.` first) — deck names carry a `UNIQUE` index, so renaming in reverse
removes the collision hazard categorically rather than by case analysis. Renaming preserves deck ids,
card scheduling, and child subdecks (Anki's rename carries `::` children along automatically).

| Flag | Default | Meaning |
|---|---|---|
| `--collection` | auto-detected | Override the collection path. |
| `--backup-dir` | `<collection dir>/backups` | Where the pre-write backup is written. |
| `--no-backup` | off | Skip the pre-write backup. |
| `--dry-run` | off | Print the plan; apply nothing. |
| `--yes` / `-y` | off | Skip the confirmation prompt. |
| `--revert` | off | Apply the inverse renaming (undo a previous run), in forward order. |

Safety order: precheck (every old name resolves, every new name doesn't exist yet) → backup → plan
print → confirm → apply → **verify** (deck-id set, every per-deck-id card count, **and every
post-apply deck name** against the plan — `verify_renumber` takes the applied rename plan and raises,
naming the offending deck id, if a rename silently didn't take even though the id and card count look
unchanged). A precheck failure exits before the backup and before any rename.

## Discrepancies found during the run

Four implementation gaps surfaced only once real numbers, real files, and a code-review pass were
involved, all fixed in the tooling rather than papered over:

- **The Verbs note type's reverse-card fronts (`Card 2`, `Card 4`) were indistinguishable** —
  Anki refused to register the note type (`CardTypeError`) because both fronts rendered only the
  deck header plus `{{Translation}}`. Fixed with a static, visible aspect label
  ("Imperfective"/"Perfective") on the reverse-front templates.
- **`attach_media`'s default resolution couldn't reach the 7 shared words' recordings.** Those 14
  files live only in the Anki media directory (Phase 8.1 correctly skipped regenerating them), never
  in the review output directory, so a single-directory `--audio-dir` search reported them missing.
  `attach_media` now resolves each predicted filename across `--audio-dir` first and the real Anki
  media directory as an automatic fallback (`--no-media-dir-fallback` opts out), with `found`/`missing`
  accounting staying exact — a genuinely absent file is still reported missing.
- **The deck header on every Mutable Words card was built from spec, not copied verbatim, and
  rendered unstyled.** The plan required the shared header (`#path`, `#deck`, the deck-name script)
  "taken verbatim" from the source note type; the shipped constants instead used a from-scratch
  `#deck-header` div with no matching CSS rule, dropping the `"Russian - "` prefix and the `#path`
  breadcrumb. Caught by the code-review gate against the live collection (round 1, blocking). Fixed
  by reading the literal markup and script directly from the real source note type's template —
  `_DECK_HEADER_HTML`/`_DECK_HEADER_SCRIPT` are now byte-for-byte what note type `1698803891108`
  actually carries, pinned by a test that reads the real collection (skipping cleanly when absent)
  and a second test asserting every id the header markup references has a matching CSS rule. The 1004
  already-imported notes were rebuilt and re-imported with the corrected header — see
  [`mutable-words-runbook.md`](mutable-words-runbook.md#post-execution-fix-the-deck-header-re-imported).
- **`verify_renumber` checked only the deck-id set and per-deck card counts, never names.** A rename
  that silently no-op'd (same id, same card count, unchanged name) would have passed undetected —
  caught by the code-review gate (round 1, blocking) even though the real run's renumber happened to
  succeed correctly. Fixed by adding `_expected_after_name()` and extending `verify_renumber` to take
  the applied rename plan and assert every post-apply name against it, covering both the renamed
  parent and any `::`-prefixed child.
